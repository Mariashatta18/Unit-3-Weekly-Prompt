# Unit 3 Weekly Prompt

## Question 2
Pick a S.O.L.I.D. design principle and explain the concept and how you can meet that principle when designing a program.

One S.O.L.I.D. design principle that I found useful is the Single Responsibility Principle. This principle means that one part of a program, such as a class, should have one main responsibility instead of trying to handle many different jobs. This can make a program easier to understand, test, and change later.

For example, if I were creating a program to manage student information, I could create a class that is responsible for storing a student's name and grades. I would not make the same class responsible for saving files, displaying menus, and handling every other part of the program. Those tasks could be handled separately. This keeps the code more organized and makes it easier to find problems.

When designing a program, I can follow the Single Responsibility Principle by thinking about the purpose of each class before I create it. If a class starts doing several unrelated tasks, I can separate those tasks into different classes or functions. I am still learning how classes work, but this principle makes sense to me because keeping each part focused on one responsibility can make larger programs easier to manage.
